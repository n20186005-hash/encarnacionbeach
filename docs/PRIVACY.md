# Privacidad

Este proyecto es un sitio informativo estático. No incluye registro de usuarios, base de datos ni formularios que almacenen datos personales. La configuración incluye Google Analytics 4 (`G-HXM22WWPKP`), que puede utilizar identificadores y cookies según la configuración y las políticas de Google. Antes de publicar, el responsable del sitio debe adaptar este texto y el mecanismo de consentimiento a la jurisdicción y al uso real del sitio.
